# Customer key review outputs

These files were generated by ImpactLint for the checked-in `customer-key-rename` scenario. They show the concrete output a data team can review or add to a pull request:

- `migration-plan.md`: coordinated rollout and owner checklist
- `schema.yml`: dbt integrity tests for the replacement key
- `impactlint-review.json`: machine-readable risk and blast-radius manifest
- `paritok-context.txt`: evidence-safe context returned after hosted compression

The full live DataHub and Paritok measurements are recorded in [`../live-review-summary.json`](../live-review-summary.json).
